LumeSync 1.0 App Review Sample Pack

The text in LumeSync-Review-Sample.txt was created specifically for LumeSync
App Review. LumeSync-Review-Sample.m4a is a synthetic narration of that same
original text, generated with the macOS system speech synthesizer. The pack
contains no third-party story, music, transcript, artwork, or adult content.

Suggested test path:

1. In Reader, tap + and import LumeSync-Review-Sample.txt.
2. In Library, tap + and import LumeSync-Review-Sample.m4a.
3. Play the audio and exercise the adjustable visual controls.
4. Queue local analysis. The first run may download the approximately 140 MB
   WhisperKit model described in the review notes.

These files are supplied only to let App Review exercise the shipping import,
reading, playback, and analysis paths without obtaining third-party content.
