Goal

Extend the Text Trance “Reading Sources” directory so that:

  1. Source content stays inside the app. Today every source opens in external Safari via @Environment(\.openURL). Replace that with an in-app browser sheet so the user never leaves Ilumionate.
  2. Add free hypnosis-story directories the user requested, all erotic / adult (18+). The original catalog deliberately excluded .adultOnly sources; this design intentionally reverses that, behind a content gate.

Non-Goals

  • No text scraping, caching, or import. Sources stay linkOnly; web → RSVP import remains the future, design-gated M4 milestone.
  • No per-source gating, no new ReadingSourceCategory. One global gate + an “18+” badge suffices.
  • No change to bundled first-party scripts.

Decisions

QuestionDecision
How does “stay in app” render?SFSafariViewController in-app sheet. Apple-maintained, full site functionality. Trade-off: black box — can’t feed the RSVP reader; that’s deferred to M4.
Adult content handlingOne-time global confirmation gate + small “18+” badge on adult cards. Not a separate category.
Scope of in-app renderingAll sources open in the in-app sheet. External Safari behavior removed entirely.

Components

1 · SafariBrowserView (new file)

A UIViewControllerRepresentable wrapping SFSafariViewController — a justified SafariServices/UIKit exception, since it is the only in-app Safari sheet API and the approach selected.

import SafariServices
import SwiftUI

struct SafariBrowserView: UIViewControllerRepresentable {
    let url: URL

    func makeUIViewController(context: Context) -> SFSafariViewController {
        let controller = SFSafariViewController(url: url)
        controller.preferredControlTintColor = UIColor(.roseGold)
        return controller
    }

    func updateUIViewController(_ controller: SFSafariViewController, context: Context) {}
}

Drive .sheet(item:) with a small Identifiable wrapper: struct BrowserDestination: Identifiable { let id = UUID(); let url: URL }.

2 · ReadingSourceDirectoryView changes

  • Remove @Environment(\.openURL).
  • Add state: browserDestination, pendingAdultURL, and @AppStorage("readingSourceAdultConfirmed") adultConfirmed.
  • Rewrite openSource(_:) to route through openAction(for:adultConfirmed:).
  • Add .sheet(item: $browserDestination) → SafariBrowserView.
  • Add a confirmation dialog for the adult gate: confirm sets adultConfirmed = true and opens the pending URL; cancel clears it.

3 · “18+” badge

In ReadingSourceCard, when source.contentRating == .adultOnly, render a small 18+ capsule beside the ImportPolicyBadge, styled consistently.

4 · Gate decision as a pure function (testability)

enum ReadingSourceOpenAction: Equatable {
    case browse(URL)
    case confirmAdult(URL)
}

func openAction(for source: ReadingSource, adultConfirmed: Bool) -> ReadingSourceOpenAction {
    if source.contentRating == .adultOnly && !adultConfirmed {
        return .confirmAdult(source.url)
    }
    return .browse(source.url)
}

                        cancel  ──► pendingAdultURL = nil
Error handling
  • Catalog URLs are URL(string:)! literals, guarded by a test that decodes the catalog and asserts every URL is non-nil http/https — a typo fails a test, never ships a crash.
  • SFSafariViewController renders its own network/load error UI; no custom handling required.

Testing

Swift Testing (@Test / #expect) in the ReadingSource test target:

  1. Catalog presence — each of the eight new ids exists.
  2. Adult rating + policy — each new source is .adultOnly and .linkOnly.
  3. URL validity — every curated URL has http/https scheme + non-empty host.
  4. Gate logic — openAction: adult+unconfirmed → .confirmAdult; adult+confirmed → .browse; non-adult → .browse.

App Store / Compliance Note

17+ rating, review-sensitive. Linking to this content raises the app’s age rating to 17+ and engages App Review Guideline 1.1 (objectionable content). The one-time gate is a mitigation, not a guarantee. Appropriate for personal / sideloaded use; revisit gating strength and the age-rating questionnaire before any public submission.
