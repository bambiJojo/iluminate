Phase Feature Extraction & Dataset Export

1Context

Build the data foundation for the learned model — before training, which is data-blocked.

Phase 2 replaces the analyzer's hand-tuned feature fusion with a learned per-second classifier → Viterbi. With only ~2 real labeled sessions, training now would overfit. Instead we build what every later step needs: turning labeled corpus cases into (features, label) rows.

  • CorpusCase carries transcripts only, not audio → features are text-derived (no prosody/audio texture yet).
  • Feature extractors are app-target: buildHitMap, TranscriptFeatureAnalyzer, TechniqueDetector, position.
  • The harness grades per-second and the planned classifier is per-second → per-second is the extraction unit.

2Goals & non-goals

Goals: a reusable deterministic PhaseFeatureExtractor (app) reusing the real extractors so train/infer features match; a PhaseDatasetExporter (test harness) that writes a training-ready CSV from the labeled corpus; unit + export tests.

Out of scope (later): audio/prosody features, the model + training pipeline + Core ML conversion + learned transition matrix, runtime model integration, corpus growth.

3Architecture

3a · PhaseFeatureExtractor (app, Ilumionate/Training/) — precompute per-second signals once, then featureVector(at:) → PhaseFeatureVector. Deterministic; the same type the eventual model calls at inference (train/infer parity).

3b · PhaseDatasetExporter (test, IlumionateTests/Corpus/) — load fixtures+synthetic+real, keep truth-bearing cases, emit one CSV row per labeled second (gray zones skipped) → Corpus/dataset/phase-features.csv.

Corpus/* (CorpusCase)
  → AudioTranscriptionResult (CorpusCase.transcriptionSegments)
  → PhaseFeatureExtractor.precompute()
  → for second in 0..<Int(duration):
       truthPhase(at: second) ?? continue   // skip gray zones
       row = featureVector(at: second) + label
  → CSV (header + rows) → phase-features.csv

6Edge cases

  • Gray-zone / no-truth second → skipped (unlabeled, not a class).
  • Empty transcript → zero signals, row still valid; case with empty truth skipped entirely.
  • Determinism → stable column order, cases sorted by id, integer-second iteration.
  • Duration → iterate 0..<Int(ceil(duration)), matching the harness bucketing.

7Testing & success

Unit: known keyword-dense transcript → assert kw_induction > 0 in the induction region, position monotonic, constant vector width, header matches value count.

Export: run over fixtures → well-formed CSV (header, row count == labeled seconds, every label a valid TrancePhase, no gray-zone rows), re-parses to the same count.

Done when: a deterministic fixed-width per-second vector reuses the real extractors, phase-features.csv is produced from the labeled corpus with gray zones excluded, and all new tests are green with no regressions.
