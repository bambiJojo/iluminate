Summary

Rework the Text Trance reader so that punctuation is removed from the displayed glyphs and promoted into control signals for word timing and motion. Three behaviors become the reader's baseline, plus an opt-in subliminal layer:

  1. Strip punctuation from display — words render as clean glyphs (drop, not drop.). Also stabilizes the ORP pivot, which today drifts on attached marks.
  2. Hyphen split — deeper-and-deeper / half-asleep split into separate short words instead of one over-long token that overflows the anchor.
  3. Punctuation → timing + motion — comma = brief pause, em-dash = medium, period/!/? = long hold + fade, ellipsis = longest drift + slow fade.
  4. Subliminal fast-flash (opt-in) — selected words blink past faster. Authored [[word]] marks take priority; if a script has none, a suggestion-word lexicon is auto-applied. Toggleable with adjustable speed, set before reading.

A deterministic, pure transform — no AI, no new dependencies. Lives in WordTokenizer + TextPacingEngine, with a small opacity change in TextTrancePlayerView and new setup controls.

Goals & Non-Goals

Goals

  • Cleaner, more legible word stream (no trailing marks, no over-long compounds).
  • More hypnotic pacing driven by the script's natural punctuation.
  • An optional subliminal layer authors can target precisely or get automatically.
  • Preserve the PacedWord.startTime / duration timeline contract so word-sizing and existing tests keep working.
Non-Goal — Feature 2 (follow-on): A text-analyzed "trance score" that generates a synchronized score driving the flashing background light and the macro pacing curve (reusing HypnosisPhaseAnalyzer / SessionGenerator / the LightScore* stack). Separate, larger generative feature with its own open questions. It slots cleanly beneath this one: punctuation timing is a per-word multiplier an analysis-driven base pace can sit under. Documented here; specced separately later.

Current State

  • WordTokenizer.tokenize splits on whitespace, keeps punctuation glued to the word, flags endsSentence.
  • WordToken = { text, endsSentence }.
  • TextPacingEngine.schedule → PacedWord { text, pivotIndex, phase, startTime, duration }; only timing rule beyond base WPM is a 2.5× hold on sentence-enders.
  • TextTranceSession.begin loops the schedule; AnchoredWord renders chars with a tinted pivot.
  • TextTranceSetupView configures arc / layers / reading speed.

Token Model

struct WordToken: Equatable, Sendable {
    let text: String          // display glyphs only — punctuation stripped
    let pause: PauseKind      // derived from trailing punctuation
    let isSubliminal: Bool    // fast-flash this word
}

enum PauseKind: Equatable, Sendable {
    case none     // no trailing pause
    case brief    // , ; :
    case medium   // — (em-dash)
    case breath   // . ! ?   → long hold + fade
    case drift    // …       → longest hold + slow fade
}

Tokenizer Pipeline

Per segment text, in order:

  1. Parse authored marks [[ … ]] first. Wraps a single word ([[relax]]) or a phrase ([[let go]]). Record subliminal words, strip delimiters.
  2. Split on whitespace.
  3. Split each token on internal hyphen - and em-dash — into sub-words. Trailing punctuation rides the last sub-word; an em-dash split also gives the preceding sub-word a medium pause.
  4. Strip trailing punctuation (. , ! ? ; : … " ' ) ]) and classify into a PauseKind.
  5. Preserve internal punctuation — apostrophes (you're, don't) and internal periods (3.5); strip surrounding quotes.
  6. Drop empty tokens (pure punctuation / standalone —), merging the pause into the preceding word (longer of the two).

Note: the tokenizer no longer exposes endsSentence; .breath / .drift supersede it.

Pacing

struct PacedWord: Equatable, Sendable {
    let text: String
    let pivotIndex: Int
    let phase: TrancePhase
    let startTime: TimeInterval
    let duration: TimeInterval
    let fade: FadeKind        // .none / .breath / .drift
    let isSubliminal: Bool
}

Fade timing is baked inside the word's duration (visible hold → fade-out), so the cumulative startTime timeline stays consistent and word-sizing/tests are unaffected.

Subliminal Layer

Precedence (two passes in schedule)

  1. Tokenize all playing segments.
  2. If any token is subliminal from an authored [[ … ]] mark → use only those.
  3. If the script has zero marks → apply the lexicon fallback (flag tokens whose lowercased display is in the set).

If the subliminal feature is toggled off, skip flagging entirely (pauses/fades still apply).

Lexicon (starter set, tunable)

deeper, relax, sleep, now, drift, calm, down, heavy, let, go,
breathe, release, still, sink, deep, rest, soften, surrender

Rendering

  • Subliminal words look identical to normal words — same font, same pivot tint. Only duration differs.
  • Opacity reset: each new word sets opacity to 1 without animation, so a flash never inherits an in-progress fade.
  • Breath/drift fade: display, hold, then animate opacity → 0 over the latter part of the word's duration (drift slower than breath). Next word's reset restores full instantly.

The session loop is unchanged in structure; it additionally publishes the current word's fade.

Settings

Add a Subliminal card to TextTranceSetupView:

  • Toggle — "Subliminal suggestions" (default on).
  • Speed picker (when on) — Gentle / Medium (default) / Deep → flash durations ~120ms / ~90ms / ~65ms. Lower = faster = less consciously legible.
enum SubliminalSpeed: String, CaseIterable, Sendable, Identifiable {
    case gentle, medium, deep
    var flashDuration: TimeInterval { /* 0.12 / 0.09 / 0.065 */ }
}
Open at review: punctuation-stripping, hyphen-split, and pause/fade are the new baseline (always on); only the subliminal layer is user-toggleable. If a master off-switch for the whole feature is wanted, raise it at spec review.

Data Flow

TranceScript.segments[].text
   └─ WordTokenizer.tokenize       → [WordToken]  (clean text + pause + subliminal)
        └─ (script-level subliminal resolution: authored marks ?: lexicon)
   └─ TextPacingEngine.schedule    → [PacedWord]  (+ duration, fade, isSubliminal)
        └─ TextTranceSession.begin → publishes currentWord / pivot / phase / fade
             └─ AnchoredWord       → renders glyphs + fade animation

Risks & Files

Risks / Edge Cases

  • Abbreviations (Dr.) get a .breath pause — acceptable, rare; documented, not special-cased.
  • Numerics (3.5) keep the internal period via trailing-only stripping.
  • AI-generated scripts can emit [[ … ]] later; not required (lexicon covers unmarked scripts).
  • Flash vs refresh — 65ms ≈ 2–4 frames; durations are wall-clock sleeps, not frame-locked.
