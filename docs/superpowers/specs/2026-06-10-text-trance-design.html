1 · Concept

A dedicated Text Trance screen where AI-generated hypnosis scripts flash word-by-word at a fixed point (RSVP), layered over the existing light entrainment and binaural beats. Reading is the induction vehicle: attention fixates on the word stream while light and sound entrain underneath. Inspired by Readrrr's focus-reading, recast as a trance modality.

        ▼                                 ▼

TextTranceSession (@Observable @MainActor coordinator)
        ├──► TextPacingEngine (new, pure logic)

        ▼
TextTranceView + Trance UI kit + photosensitivity safety
Key boundary: TextPacingEngine knows nothing about UI or script content. Input: (words, phase, settings, clock) → output: timed word events. Fully unit-testable — same philosophy as the light engine.
  • TranceScript — Codable model: metadata + ordered phase segments.
  • TranceScriptLibrary — discovers/validates bundled scripts (LightScoreReader posture: bad files excluded, never crash).
  • TextTranceSession — phase progression, arc handling, layer lifecycle, emergence signaling.
  • TextPacingEngine — word timing = baseWPM (per phase) × deepening curve × user speed; ~2.5× hold at sentence punctuation; ORP pivot index; lock-mode opacity modulation (pivot letter never flickers).
  • TextTranceView — library → setup → control-free player (tap-and-hold to end).
4 · Script JSON Format 
{
  "schemaVersion": 1,
  "id": "deep-drift-01",
  "title": "Deep Drift",
  "theme": "relaxation",
  "supportedArcs": ["fullText", "handoff"],
  "language": "en",
  "source": { "kind": "bundled", "generator": "corpus-gen 1.4", "reviewed": true },
  "segments": [
    { "phase": "induction",  "text": "Allow your eyes to rest softly…",   "pacing": { "baseWPM": 140 } },
    { "phase": "deepening",  "text": "Deeper and deeper with every word…", "pacing": { "baseWPM": 100 } },
    { "phase": "suggestion", "text": "You find calm easily now…",          "pacing": { "baseWPM": 85 } },
    { "phase": "emergence",  "text": "In a moment you will return…",       "pacing": { "baseWPM": 130 }, "arcs": ["fullText"] },
    { "phase": "handoffCue", "text": "And now… let your eyes gently close…", "arcs": ["handoff"] }
  ]
}
  • Phases reuse HypnosisMetadata.Phase + new handoffCue.
  • arcs: makes segments arc-conditional — one file serves both arcs.
  • baseWPM is a hint; engine multiplies by curve and user speed.
  • source.reviewed → "reviewed" badge in the library.
5 · Runtime Data Flow
  1. User picks script + options; session filters segments by arc, tokenizes, starts layers.
  2. Engine emits (word, pivotIndex, displayDuration, opacityCurve) events.
  3. View aligns pivot letter to fixed anchor; background pulse via FlashController at low intensity.
  4. Handoff: after cue — text fades, light ramps to target frequency, binaural continues, timer runs remainder; emergence = frequency ramp + optional chime, no text.
  5. Sleep + handoff: no emergence — light and audio fade out, session self-terminates.
ORP rule: 1-letter → 1st; 2–5 → 2nd; 6–9 → 3rd; 10+ → 4th. Pivot tinted with Trance accent.
6 · UI Flow
  1. Library — theme chips (All/Relax/Sleep/Focus/Suggest); cards: title, theme, read time, arc chips, reviewed badge; greyed-out "Generate new script…" card reserves the AI milestone.
  2. Setup — arc control ("Read → eyes close" / "Read everything"); toggles: light pulse, binaural (headphones note), entrainment-lock (experimental); speed: Slow/Natural/Brisk; post-handoff duration + emergence style.
  3. Player — no visible controls; fixed-point ORP word over radial pulsing field; thin phase rail; tap-and-hold to end; tick marks fade after induction.
7 · Error Handling & Safety
  • Malformed scripts excluded at load with a log — never crash the picker.
  • Unsupported arc simply isn't offered in setup.
  • Binaural failure (no headphone route): continue without, quiet notice.
  • Entrainment-lock gated behind photosensitivity validation; settings-gated until comfort-tested.
  • All bundled scripts human-reviewed; self-suggestion themes strictest.
  • fullText segments must contain no eyes-closure phrasing — enforced by regression test.

9 · Milestones & Out of Scope
  1. M1 — Core engine + bundled library: schema, loader, pacing engine (RSVP + ORP), screens, both arcs, layer integration, hand-reviewed scripts (all four themes via CorpusGenerator offline).
  2. M2 — Entrainment-lock: settings-gated, safety-validated, comfort testing.
  3. M3 — AI generation: in-app generation, personalization, un-grey the library card; generated scripts marked reviewed: false.

Out of scope: LightSession schema integration; narrated-audio caption sync (WordTimestamp "trance karaoke"); non-English scripts.
