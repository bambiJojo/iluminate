Decisions (user-confirmed)
  1. Fully shelf-first. The vertical Audio Files list leaves the Library root. "All Files" is a carousel; its "See all" pushes the full sortable list as its own screen.
  2. Shelf set & order: Recently Played, Favorites, Playlists, Artists, Analyzed, All Files, Built-in Sessions. Empty shelves stay hidden.

New screen — LibraryAllFilesView

Pushed via LibraryDestination.allFiles. Hosts the existing LibrarySessionsList (sort menu, swipe actions, context menus, SessionDetailView links) over AuroraBackground, native title "Audio Files". Owns its @State sortOption; sorts via LibraryShelfContent.sortedFiles(from:by:). LibrarySessionsList moves out of LibraryView.swift into this file; LibraryView drops sortOption and cachedSortedFiles.
