Player & Reader Orbital Redesign

Design spec · 2026-07-02 · branch feature/player-redesign · supersedes the 2026-06-30 visual-elevation pass (shipped in e4ad5db)
The problem: the player's bottom stack (scrubber + transport + pills + toggles) still reads as a utility panel.
The answer: an orbital command cluster + whisper scrub line — one control grammar shared by the player and the reader. Everything orbits the light; nothing is removed, everything relocates.

1 · Shared control grammar

Three new small components used by both screens:

ScrubWhisperLine

  • Three states: whisper (2 pt, faint) → prominent (controls visible) → scrubbing (~6 pt under touch, floating info overlay, full-width drag).
  • Overlay is caller-supplied: player shows monospaced 12:34 / 30:00; reader shows phase name + word 412 / 890.
  • VoiceOver: adjustable action (player ±15 s, reader ±sentence) — the 2 pt line itself is not the target.

BloomSliderCapsule

  • Floating glass slider that blooms above the satellite row (volume, light level, speed). One open at a time; melts away on dismiss; instant under reduce-motion.

SatelliteButton + cluster styles

  • Icon-only ghost circles (teal when active) and the shared cluster styles: solid-teal circular action button + ghost ring buttons.

2 · Player — UnifiedPlayerView

sessionaudio-lightplaylist Resting layout, top → bottom: ghosted top bar → hero orb → title block → command cluster (−15 s · play · +15 s) → satellite row (◐ light sync · 🔊 volume · ☀ light level · ···) → whisper line.

  • Slider satellites bloom a capsule; ◐ stays a toggle (photosensitivity warning flow intact).
  • ··· opens a compact overflow sheet holding the mode extras: sync options, bilateral/binaural, smart transitions, track list — reusing today's section views.
  • Seeking: touch the line → it thickens with floating time; drag full-width; reuses the view model's existing seek path. Playlist scrubs within the current track; paused stays paused.
  • Retired from the resting layout: scrubber bar, labeled pills, GlassCard panels, inline toggles.

flashcolor-pulse Full-screen visuals unchanged; no finite duration → no line/time. Their revealed controls adopt the same cluster + satellites grammar.

3 · Reader — TextTrancePlayerView

Resting state untouched: word, phase atmosphere, whisper line, long-press exit, background auto-pause.

  • Revealed: the capsule is replaced by the cluster — ✕ End · pause/play · ⚙ Settings — with satellites ⚡ speed (blooms live WPM slider), ◐ light, 〰 binaural. Deep settings stay in the sheet.
  • Script scrubbing (new): TextTranceSession.seek(toWordIndex:) — pauses ticking, repositions (clamped), resumes on release (or stays paused). Overlay shows phase + word position; line gradient tinted by phases crossed. Post-handoff tail: display-only.
  • Word fade state snaps clean on reposition; word-sequence invariance makes an index a stable position.

4 · Edge cases & accessibility

  • Reduce-motion: no bloom/thicken animation, static orb, no motion-only info.
  • All satellites and cluster buttons labeled; scrub line adjustable via VoiceOver actions.
  • One-bloom invariant; reveal/hide closes blooms.
  • Safety: light-sync alert, safety overlay, session lock — untouched.

5 · Testing & verification

  • Unit: reader seek (clamping, phase-at-index, resume-from-index, paused-stays-paused, snapshot consistency, post-handoff no-op); bloom exclusivity; player fraction→time mapping incl. playlist bounds.
  • Live (iPhone 17 sim): all five modes + reader reveal/bloom/scrub + reduce-motion pass, screenshots each.
  • Build: xcodebuild … -scheme Ilumionate build clean.

6 · Non-goals  ·  7 · Files

  • No playback/light-engine/pacing changes beyond seek(toWordIndex:); no immersion mode; no setup/entry/mini-player changes.
