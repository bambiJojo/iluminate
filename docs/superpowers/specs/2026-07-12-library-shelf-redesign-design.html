Library Shelf Redesign

Apply the reader tab's shelf-first carousel style to the main Library tab, so both tabs share the same Apple Music-style visual language: a vertical scroll of horizontal card shelves.

Decisions (user-confirmed)
  1. Shelves + full list below. Curated groups become carousel shelves; the complete Audio Files list stays as a vertical list at the bottom with its sort menu.
  2. Category rows become content shelves. Playlists, Favorites, and Built-in Sessions each become a carousel of actual item cards with “See all” links. The Analysis Queue stays a compact status surface, not a shelf.
  3. Reader-style header. Custom in-scroll bold “Library” title with a circular + button, replacing navigationTitle("Library") and the toolbar +.
Approach

Reuse the shelf mechanics — CarouselRow (view-aligned paging, 86%-width cards with next-card peek, scale/fade scroll transition, full-width single card) plus LiminalCard and the section-header pattern — but build Library-specific card views.

The reader's private card components (MetricPill, TagChip, HistoryCard, …) are not extracted; they stay private to the reader.

Layout — one vertical scroll over AuroraBackground
  • Headerchrome
    Bold “Library” (28pt, matching the reader's LibraryHeader) + circular + button. + opens the existing Add Sessions sheet (AudioLibraryView). Nav bar hidden on this root screen only; pushed screens (Favorites, Built-in Sessions) keep their native titles.
  • Analysis Queue status cardstatus · conditional
    Rendered only when queue count > 0. Compact glass row: waveform icon, “Analysis Queue”, count. Tap opens the existing queue sheet (AnalyzerView).
  • Recently Playedshelf
    CarouselRow of cards: SessionGlowDot (40pt tile) + title + duration + gradient “Play” pill (mirrors the reader's Continue Reading card). Tap plays with lights — UnifiedPlayerView(mode: .audioLight). Hidden when empty.
  • Favoritesshelf
    Same card grammar with the heart accent (Color(hex: "E85D75")). “See all” pushes LibraryDestination.favorites. Hidden when empty.
  • Playlistsshelf
    Cards: rose-gold icon tile, name, item count + total duration. Tap plays — UnifiedPlayerView(mode: .playlist(playlist:)). “See all” opens PlaylistLibraryView sheet. Context menu: Play, Open Playlists. Hidden when empty.
  • Built-in Sessionsshelf
    Cards from LightScoreReader bundled sessions: sparkles tile, display name, duration. Tap plays — UnifiedPlayerView(mode: .session(session:, audioFile: nil)). “See all” pushes LibraryDestination.builtInSessions.
  • Audio Filesfull list · unchanged
    Existing vertical LibrarySessionsList: sort menu, swipe actions, context menu, empty-state hint.
  • Tab-bar clearance spacerchrome
    Existing TranceSpacing.tabBarClearance pattern.
◆
Shelves cap at 10 items each; full sets live behind “See all” / the bottom list.

Data & Derivation

Shelf-content derivation moves into a small pure helper so it is unit-testable:

struct LibraryShelfContent {
    static let shelfCap = 10
    static func recents(from files: [AudioFile]) -> [AudioFile]     // lastPlayed desc, cap
    static func favorites(from files: [AudioFile]) -> [AudioFile]   // favorite only, cap
    static func shelfPlaylists(from playlists: [Playlist]) -> [Playlist] // cap
}

LibraryView.recomputeDerivedCollections() delegates to these. Sorting of the bottom Audio Files list is unchanged.

Error & Empty Handling
  • Empty shelves render nothing (reader pattern) — no placeholder cards.
  • Playlist / built-in-session load failures degrade to hidden shelves; no alerts.
  • Audio-file loading keeps the existing repairing loader (AudioLibraryStore.loadRepairingStoredFiles()).
  • Empty audio list keeps the existing “Tap + to add your first session” hint.
Testing & Verification
  1. Unit tests for LibraryShelfContent — recents ordering, favorites filter, caps, empty inputs.
  2. Build via xcodebuild; run existing test suite (some analyzer test failures pre-exist on this branch).
  3. Simulator run to visually verify: shelf paging + peek, single-item full-width card, “See all” navigation, tap-to-play for each shelf type, hidden nav bar on root but visible titles on pushed screens, tab-bar clearance.
Out of Scope
  • No changes to the reader tab beyond the CarouselRow comment.
  • No changes to AudioLibraryView, PlaylistLibraryView, SessionLibraryView, favorites view internals, or playback.
  • No extraction of the reader's private card components.
